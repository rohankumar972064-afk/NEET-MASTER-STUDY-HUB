5. Publish Checklist

  1. Create a GitHub repository and enable GitHub Pages.
  2. Upload the website files once.
  3. Create a fine-grained GitHub token limited to this repository with Contents: Read and write.
  4. Enter owner, repo, branch and token above.
  5. Upload Excel/CSV and validate.
  6. Click Publish to GitHub. The JSON files are committed automatically.

Security: Never paste a token into public code or share it. For a multi-admin/public production system, use a backend or GitHub App instead of exposing a write token in a browser.
